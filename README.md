# Ciclo — 6 semanas keto

App web sencilla para seguir un ciclo de 6 semanas: adaptación, cetosis y reinserción, con recetas, semáforo de alimentos y rutinas cortas de movimiento.

## Cómo abrirla

```bash
npm install
npm run dev
```

En local: [http://localhost:5173](http://localhost:5173).

En el móvil: [https://ym4jk6ky7h-crypto.github.io/CicloKeto/?instalar=1](https://ym4jk6ky7h-crypto.github.io/CicloKeto/?instalar=1)

El progreso se guarda en el navegador de cada persona.

## Contenido

El recetario, el semáforo de alimentos, las guías de ayuno y de proteína salen de los PDFs del Método KetoActivate. Los menús diarios de las semanas 1 y 2 completas no estaban en el escritorio; hay un plan práctico por fases que se puede ampliar.
